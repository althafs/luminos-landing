# Luminos Landing Page (React + CRA + Tailwind)

This is a mockup landing page for **Luminos**, built with:
- React (Create React App)
- Tailwind CSS (for styling)
- Recharts (dynamic chart demo)

## Features
- Branded header + CTA
- Three product highlight sections
- Claims performance chart (dynamic JS)
- Book a Demo form (first name, last name, company, job title, email)

## How to Run
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run locally:
   ```bash
   npm start
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Deployment
You can configure GitHub Pages or any hosting by serving the `build/` folder.
